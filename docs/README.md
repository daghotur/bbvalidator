## Ключевые цифры

- **Датасет:** 425 178 образцов / 141 726 нативных цепей (PDB, X-Ray ≤ 2.0 Å, длины 50–700), 7 стратегий декоев, сплит по родительской цепи (анти-утечка).
- **Test:** ROC-AUC **0.979**, Accuracy **94.7%**, ECE **0.0098** (гибрид MPNN+Transformer); базлайны MLP и GPS обучены по идентичному протоколу.
- **OOD (MotifBench, 18 000 структур пяти генераторов):** значимая корреляция P(fold) ↔ scRMSD (до −0.46), корректное ранжирование генераторов по качеству.
- **Неопределённость:** MC-Dropout с однократным вычислением физического фронтенда.

├── checkpoints/                # best/last чекпоинты
