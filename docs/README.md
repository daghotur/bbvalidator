## Ключевые цифры

- **Датасет:** 340 390 образцов / 141 726 нативных цепей (PDB, X-Ray ≤ 2.0 Å, длины 50–700), 7 стратегий декоев (две borderline исключены), сплит по **кластерам последовательностей 30% идентичности** — 12 459 групп, 0% общих PDB-записей между сплитами.
- **Test (51 059 образцов, анти-гомологичный сплит):** ROC-AUC **0.9999**, Accuracy **0.9981**, ECE **0.0017** у гибрида; MLP-базлайн даёт ту же AUC 1.0000. Задача насыщена, батарея не различает архитектуры и не ловит регрессий (docs/05, 5.1). Числа 0.979 / 94.7% относятся к датасету до исключения borderline-декоев.
- **OOD (MotifBench, 15 000 структур пяти генераторов):** внутримотивное ранжирование против метрики MotifBench ($\mathrm{scRMSD} = \min_k$ по 8 последовательностям). На **невиданных** генераторах: GPDL — Spearman 0.63, **95% потолка оракула**; ODesign-Rigid — 0.38, **78%**. На генераторах из дообучения (RFdiffusion, RFdiffusion-AA, EvoDiff) 91–93%, но это in-sample. Потолок измерен независимо, split-half по последовательностям.
- **Экономика скрининга:** на трудных мишенях (дизайнируемых < 25%) фильтр сокращает число дорогих проверок до первого рабочего остова в 4.6–16.8 раза; одна проверка ESMFold стоит 2300–13800 прогонов фильтра. На лёгких мишенях выигрыш 1.1–1.5× — там фильтр не нужен.
- **Оракул:** предсказания переносятся на AF2 как независимый рефолдер (83% и 81% потолка против 86% и 90% на «своём» ESMFold) — модель не сводится к детектору причуд ESMFold.
- **Неопределённость:** MC-Dropout с однократным вычислением физического фронтенда.

## Карта репозитория

Всё, что лежит в пакетах, запускается модулем из корня: `python -m analysis.scrmsd`.

```text
.
├── inference.py                # CLI-инференс PDB с MC-Dropout
├── filter_designability.py     # батчевый фильтр PASS/FAIL с гейтами
│
├── training/
│   ├── hybrid.py               # обучение основной модели
│   ├── soft.py                 # дообучение на мягкую метку log1p(scRMSD)
│   ├── soft_multitask.py       # мультизадачная починка aux-голов + native-якорь
│   ├── build_lddt_labels.py    # по-остаточная метка CA-lDDT из рефолдов MotifBench
│   ├── perresidue.py           # дообучение только на по-остаточную метку
│   └── joint.py                # совместный лосс: по-остаточный lDDT + глобальный scRMSD
│
├── evaluation/
│   ├── eval_model.py           # батарея метрик на сплите (JSON + markdown)
│   ├── eval_generated.py       # скоринг выходов внешних генераторов (OOD)
│   └── benchmark.py            # латентность/пропускная способность
│
├── analysis/
│   ├── scrmsd.py               # корреляция P(fold) ↔ scRMSD по генераторам
│   ├── logits_ranking.py       # насыщение выхода против потери сигнала
│   ├── enrichment.py           # фактор обогащения скрининга
│   ├── oracle_ceiling.py       # потолок оракула, split-half по последовательностям
│   ├── label_choice.py         # выбор агрегатора scRMSD: mean против min
│   ├── relabel.py              # перемер моделей под исправленной меткой
│   ├── motif_bias.py           # внутримотивный lift, исключение насыщенных мотивов
│   ├── perresidue.py           # сравнение режимов супервизии soft / perres / joint
│   ├── second_oracle.py        # перенос на AF2 как независимый оракул
│   ├── baselines.py            # дешёвые бейзлайны против модели
│   ├── economics.py            # экономия дорогих проверок по сложности мишени
│   ├── length_stress.py        # стресс-тест по длине 50-1000 (Scaffold-Lab)
│   └── fadiff_sc.py            # self-consistency выходов собственного генератора
│
├── common/
│   ├── motifbench.py           # пути MotifBench, SCRMSD_AGG, парсер *_eval_results.csv
│   ├── structures.py           # чтение PDB и сборка батчей с паддингом
│   ├── scoring.py              # скор модели «меньше = дизайнируемее»
│   └── ranking.py              # precision@top, lift, split-half метки
│
├── dataset/                    # сбор данных, декoi, таргеты, сплиты, dataloader
├── preprocess/                 # биофизический фронтенд + PCA fit + pytest-тесты
├── model/                      # энкодер, головы/лосс, метрики (AUC/PR-AUC/ECE)
├── baselines/                  # MLP- и GPS-энкодеры для честного сравнения
├── checkpoints/                # best/last чекпоинты
├── results/                    # JSON/CSV прогонов evaluation/ и analysis/ (git-ignored)
├── figures/                    # графики анализов
└── docs/                       # эта документация
```
