## Ключевые цифры

- **Датасет:** 425 178 образцов / 141 726 нативных цепей (PDB, X-Ray ≤ 2.0 Å, длины 50–700), 7 стратегий декоев, сплит по родительской цепи (анти-утечка).
- **Test:** ROC-AUC **0.979**, Accuracy **94.7%**, ECE **0.0098** (гибрид MPNN+Transformer); базлайны MLP и GPS обучены по идентичному протоколу.
- **OOD (MotifBench, 15 000 структур пяти генераторов):** внутримотивное ранжирование против метрики MotifBench ($\mathrm{scRMSD} = \min_k$ по 8 последовательностям) — Spearman 0.37–0.83, модель забирает **88–97% потолка оракула** на четырёх генераторах из пяти (ODesign-Rigid — 74%, единственный с существенным запасом). Потолок измерен независимо, split-half по последовательностям.
- **Экономика скрининга:** на трудных мишенях (дизайнируемых < 25%) фильтр сокращает число дорогих проверок до первого рабочего остова в 4.6–16.8 раза; одна проверка ESMFold стоит 2300–13800 прогонов фильтра. На лёгких мишенях выигрыш 1.1–1.5× — там фильтр не нужен.
- **Оракул:** предсказания переносятся на AF2 как независимый рефолдер (81–83% потолка против 89–92% на «своём» ESMFold) — модель не сводится к детектору причуд ESMFold.
- **Неопределённость:** MC-Dropout с однократным вычислением физического фронтенда.

## Карта репозитория

```text
.
├── train_model.py              # обучение основной модели
├── eval_model.py               # батарея метрик на сплите (JSON + markdown)
├── eval_generated.py           # скоринг выходов внешних генераторов (OOD)
├── inference.py                # CLI-инференс PDB с MC-Dropout
├── benchmark.py                # латентность/пропускная способность
├── analysis_scrmsd.py          # корреляция P(fold) ↔ scRMSD; SCRMSD_AGG — метка проекта
├── analysis_fadiff_sc.py       # self-consistency выходов собственного генератора
├── filter_designability.py     # батчевый фильтр PASS/FAIL с гейтами
├── train_soft.py               # дообучение на мягкую метку log1p(scRMSD)
├── build_lddt_labels.py        # по-остаточная метка CA-lDDT из рефолдов MotifBench
├── train_perresidue.py         # дообучение только на по-остаточную метку
├── train_joint.py              # совместный лосс: по-остаточный lDDT + глобальный scRMSD
├── analysis_oracle_ceiling.py  # потолок оракула, split-half по последовательностям
├── analysis_label_choice.py    # выбор агрегатора scRMSD: mean против min
├── analysis_relabel.py         # перемер моделей под исправленной меткой
├── analysis_motif_bias.py      # внутримотивный lift, исключение насыщенных мотивов
├── analysis_second_oracle.py   # перенос на AF2 как независимый оракул
├── analysis_baselines.py       # дешёвые бейзлайны против модели
├── analysis_economics.py       # экономия дорогих проверок по сложности мишени
├── analysis_length_stress.py   # стресс-тест по длине 50-1000 (Scaffold-Lab)
├── dataset/                    # сбор данных, декoi, таргеты, сплиты, dataloader
├── preprocess/                 # биофизический фронтенд + PCA fit + pytest-тесты
├── model/                      # энкодер, головы/лосс, метрики (AUC/PR-AUC/ECE)
├── baselines/                  # MLP- и GPS-энкодеры для честного сравнения
├── checkpoints/                # best/last чекпоинты
└── docs/                       # эта документация
```
