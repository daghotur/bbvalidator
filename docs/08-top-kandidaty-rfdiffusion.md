# 08 — Топ-кандидаты: полный поток RFdiffusion

Снимок прогона `filter_designability.py` на полном потоке RFdiffusion из MotifBench: 3000 структур, гейт `--max-scrmsd 3.5` (режим покрытия), ранжирование — `soft_model.pth`, диагностика похожести на натив — `soft_model_mt.pth` (раздел 5.4). Истинный scRMSD — оракул MotifBench (средний RMSD рефолдинга по дизайнуемым секвенциям). Дата прогона: 2026-08-12.

Воспроизведение:

```bash
python filter_designability.py -i data/ood/rfdiffusion/scaffolds --max-scrmsd 3.5 -o filter_results.csv
```

## Наблюдения

1. **Калибровка на топе почти точная**: предсказанный scRMSD совпадает с истинным в пределах ~0.1 Å (0.61 против 0.65, 0.68 против 0.69). Сжатие шкалы, характерное для середины распределения (раздел 5.4), на топе не проявляется — именно там, где это важно для скрининга.
2. **Топ-30 целиком из одного мотива** (22_1BCF, L=125) — глобальное ранжирование сначала вычерпывает самые «лёгкие» мотивы; остальные мотивы идут глубже по списку.
3. **Диагностика согласна с ранжированием** на топе (натив-диаг 0.9–2.6 Å, расхождений нет); маркеры расхождения появляются глубже по списку.
4. Оговорка раздела 5.4 действует: истинный scRMSD здесь — мнение ESMFold-рефолдинга (оракул MotifBench), а не эксперимент.
